# NewsFlow

Простой и удобный новостной агрегатор. Ищи новости по ключевым словам и сохраняй понравившиеся в избранное.

## Возможности

- Поиск новостей по любому запросу
- Добавление в избранное (сохраняется в браузере)
- Избранное не пропадает после перезагрузки
- Адаптивный дизайн для телефонов и компьютеров

## Технологии

- Node.js + Express — серверная часть
- NewsAPI — источник новостей
- LocalStorage — хранение избранного
- HTML/CSS/JS — интерфейс
