## Ключ для новостей

1. Зарегистрируйся на https://newsapi.org/register
2. Скопируй API ключ из личного кабинета
3. Создай в корне проекта файл `.env`
4. Вставь туда:

NEWS_API_KEY=твой_скопированный_ключ
PORT=3000
